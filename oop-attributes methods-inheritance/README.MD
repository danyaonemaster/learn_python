Вот по 10 заданий на каждую из указанных тем по Python OOP. Все задания — без тестов, как ты просил.

🧩 Тема 1: Атрибуты

1. + Создай класс Person с атрибутами name и age. Создай экземпляр и выведи его атрибуты.
2. + В классе Car задай атрибуты brand, model, year. Сделай метод info, который выводит их.
3. Добавь в класс Circle атрибут radius. Вычисли площадь круга по атрибуту.
4. Создай класс Student с атрибутом grades — список оценок. Добавь метод для вывода средней оценки.
5. В классе Book задай title и author. Добавь метод, возвращающий строку вида "Автор: Название".
6. Напиши класс BankAccount с атрибутами owner, balance. Реализуй методы для пополнения и снятия.
7. В классе Rectangle добавь width и height. Сделай метод area, возвращающий площадь.
8. Создай класс Laptop с атрибутами brand, ram, cpu. Выведи все через str.
9. В классе Employee добавь атрибут position. Проверь, можно ли изменить его после создания.
10. Создай класс Animal с атрибутами name и sound. Добавь метод make_sound, который печатает звук.

🧩 Тема 3: Методы классов (@classmethod)

1. Сделай класс Person, у которого есть @classmethod from_birth_year(cls, name, year), создающий человека по году рождения.
2. В Book реализуй from_string(cls, book_str), который принимает строку "Автор - Название" и создаёт экземпляр.
3. В Car сделай метод default_car(cls), возвращающий Car("Toyota", "Corolla", 2020).
4. Напиши User с classmethod guest(cls), создающий гостевого пользователя.
5. В классе Rectangle, сделай from_square(cls, size), создающий квадрат.
6. В Temperature, добавь from_fahrenheit(cls, f) для создания по Фаренгейту.
7. Класс Account пусть имеет create_with_bonus(cls, owner), создающий аккаунт с бонусом.
8. В Session сделай метод empty(cls), возвращающий сессию без пользователей.
9. В Order, создай from_dict(cls, data) — инициализация из словаря.
10. В Point реализуй origin(cls) — возвращает точку (0, 0).
